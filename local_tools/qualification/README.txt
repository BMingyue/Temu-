Temu 小地毯商品资质与合规本地自动化
====================================
版本：2.3.6

使用方法
--------
1. 打开织品工作台，进入“商品资质与合规”。
2. 根据任务点击“开始上传实拍图和 GCC”或“开始确认警示声明”。
   需要脱离工作台单独检查时，也可使用本目录内的 START、CHECK 和 STATUS 启动器。
3. 在专用 Chrome 中登录，并切换到本次需要上传的目标店铺。
4. 程序弹出“确认目标店铺”窗口后，核对店铺并点击“确认店铺并开始”。
5. 点击确认前不会上传文件，也不会提交合规确认；取消或关闭窗口会安全退出。
6. 上方任务会进入“商品资质”，筛选“未发布到站点”，逐个上传并提交。
7. 下方任务会进入“商品合规信息”，逐个确认待确认的小地毯易燃警示声明。

环境依赖
--------
- 安装包已内置运行引擎，不依赖系统 Node.js、npm、Python、Codex 或其他命令。
- 启动器只调用本文件夹内的 runtime\node.exe。
- 优先使用工作台内置的专用浏览器，无需额外安装 Chrome；独立使用且没有内置浏览器时，兼容标准位置已安装的 Google Chrome。
- 程序只控制自己创建的专用 Chrome，不操作日常使用的普通 Chrome。

程序固定读取
------------
工作台\local_tools\qualification\assets

上传对应关系
------------
商品主体 / 正视图   ← 产品正面图.jpg
商品主体 / 侧视图   ← 产品侧视图.jpg
商品主体 / 标签图   ← 水洗唛.jpg
商品外包装 / 正视图 ← 包装正视图.jpg
GCC 检测报告        ← 自制证书3.0(1).pdf

自动处理范围
------------
- 商品状态必须为“未发布到站点”。
- 只处理 GCC、待上传、16 CFR part 1631 且属于地垫/地毯的商品。
- 已完成、已删除、不符合条件或没有可用“上传资质”入口的商品会跳过。
- 当前页处理完后自动检查下一页，直到最后一页没有符合条件的待上传商品。
- 如果 Temu 在提交后自动跳回第 1 页，程序会越过已检查页并继续扫描，不会提前结束。

警示声明确认范围
----------------
- 只处理商品合规信息中属于地垫/地毯、且“小地毯易燃警示声明”为“待确认”的商品。
- 打开“编辑”后，只有页面已经选中警示声明、责任确认框已经勾选时才会点击“确认”。
- 不会填写加州 65 号提案、包装材料，也不会上传图片或 PDF。
- 当前页处理完后自动翻页，直到最后一页没有符合条件的商品。
- 同一次运行记录已处理 SPU，提交结果未更新、页面异常或超时会立即停止。

防重复与失败保护
----------------
- 上方四张实拍图已经完整存在时，直接跳过图片编辑并补齐下方 GCC PDF。
- 只有部分图片时会进入“编辑图片”，已有槽位不会再次上传，只补齐缺少的图片。
- 每上传一张图片都会重新按“区块 + 槽位名称”定位，避免上传后按钮移位导致错位。
- 同一次运行永久记录已处理的 SPU，页面状态延迟时也不会重复提交。
- 四张图片必须识别成功，PDF 必须显示已选中，才会点击资质“确认”。
- 提交后必须检测到列表状态更新或成功提示，才会继续下一个商品。
- 上传失败、识别失败、页面改版或超时会立即停止，不会盲目跳过。
- 同一时间只允许一个任务运行，防止重复双击造成重复上传。

店铺确认
--------
- 每次双击任一 START 启动器都会显示醒目的本地确认窗口。
- 请先在专用 Chrome 右上角切换好店铺，再点击“确认店铺并开始”。
- 点击确认前绝不会上传图片、PDF 或提交警示声明确认。

检查与记录
----------
- 双击“CHECK.cmd”：检查内置引擎、Chrome、四张图片和 PDF 是否齐全合规。
- 双击“STATUS.cmd”：查看最近一次运行日志。
- 双击“CHECK-COMPLIANCE.cmd”：检查警示声明确认工具和专用 Chrome。
- 双击“STATUS-COMPLIANCE.cmd”：查看最近一次警示声明确认日志。
- 专用登录资料：本工具目录内的 state\ChromeProfile
- 代码、运行引擎、确认窗口、运行锁、日志和专用 Chrome 资料均包含在工作台内，不依赖旧任务目录。
- 运行锁会采用同样的可写目录回退，不再因 uploader.lock 权限不足而中止。
- 上传日志：程序文件夹内 logs\latest.log 和 logs\status.json
- 确认日志：程序文件夹内 logs\compliance-latest.log 和 logs\compliance-status.json

停止
----
直接关闭黑色运行窗口即可停止。若当前单张文件已开始上传，该文件可能已经到达 Temu；
下次启动时，程序会读取页面实际槽位和资质状态，避免重复上传。
