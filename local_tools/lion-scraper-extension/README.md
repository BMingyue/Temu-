# TEMU商品采集器

黑金科技风格的浏览器插件，用于采集TEMU商品数据。

## 功能特性

- 🎯 圆形悬浮球，可拖拽定位
- ⚡ 黑金科技风格UI
- 📊 可配置采集页数、翻页延迟、销量范围
- 🚀 开始/停止/导出功能
- 💾 自动保存设置
- 📝 导出TXT格式（ID-----标题-----主图URL）

## 采集数据

插件会采集以下信息：
- 商品ID
- 商品标题
- 主图URL（高清图）
- 价格（用于筛选）
- 销量（用于筛选）

## 导出格式

导出的TXT文件格式为每行一个商品：
```
商品ID-----商品标题-----主图URL
```

示例：
```
601104979636313-----Plus Size Women's T-Shirt-----https://img.kwcdn.com/product/open/xxx.jpeg
606062447006729-----Men's Summer T-Shirt-----https://img.kwcdn.com/product/open/yyy.jpeg
```

## 安装方法

1. 打开Chrome浏览器，进入 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `temu-scraper` 文件夹

## 使用说明

1. 访问 TEMU 搜索页面
2. 页面右下角会出现金色悬浮球
3. 点击悬浮球打开控制面板
4. 选择采集页面类型（搜索商品/为你精选/店铺商品/探索好物）
5. 配置采集参数：
   - 采集页数：要采集多少页
   - 翻页延迟：每页之间的等待时间（秒）
   - 最小销量：筛选条件
   - 最大销量：筛选条件
6. 点击"开始"按钮开始采集
7. 采集完成后点击"导出数据"按钮导出TXT文件

## 注意事项

- 采集功能基于页面DOM结构，如果TEMU更新页面可能需要更新选择器
- 建议设置合理的翻页延迟，避免请求过快
- 导出的图片URL为高清图（800px宽度）
- 请遵守TEMU网站的使用条款
