# 织品工作台 · 统一助手 0.20.11

0.20.11 按用户确认的商品信息标志判定加速器开关：“流量加速中”（含长期加速）为已开启，没有标志为未开启。按完整在售清单每20个SPU读取同店美国站的完整加速中集合，返回集合记开启，其余目标记未开启；不带待开启资格、Max或价格条件，不再读取不能覆盖全部商品的加速效果详情。请求失败、条数不全、店铺/站点/商品范围异常时本批停止，不把失败当未开启。整份清单核对完成且哈希未变才报完成。旧的待确认记录需新版重新采集后更新。

0.20.10 对流量列表未返回的在售SPU补查原生单品加速记录。仅商品与站点回显匹配，或详情中的SKC全部属于本轮完整在售快照的该SPU时，才采用明确开关状态；已结束状态2按未开启处理。空历史、默认0、身份不明或单品接口不可用继续保留待确认，并保存具体原因，不把缺席改为未开启。

0.20.9 按最新完整在售商品清单采集美国站加速器开关状态。每批最多20个SPU，直接读取同店原生流量列表接口的明确flowGrowStatus，不使用“流量加速中”“待开启”或Max资格筛选，不依赖页面翻页和可见行计数。完成时核对在售清单是否变化，分别显示已开启、未开启、待确认；平台没返回或状态不明确的商品不会被当作未开启。需要工作台后端同步更新，并重新加载扩展、刷新商家后台与工作台。

0.20.8 修复加速器快速筛选已经选中却被误报“选择未生效”的问题。美国站原生快速筛选卡片通过内部勾选图标表示选中，插件现在只在对应卡片内核验该图标，同时保留原有 aria、单选框和样式状态兼容。重复页、总数不符、店铺校验和未读商品保持待确认的保护不变。已加载此文件夹的 Chrome/Edge 需要重新加载扩展、刷新商家后台后生效；本次本地回归通过不代表已在真实店铺完成采集。

0.20.6 避免单个时间范围暂无有效汇总时阻断其他范围和后续订单。仅概览和趋势接口均成功但没有任何有效数值时，记录缺失范围、保留旧值并继续；登录、权限、超时和其他错误仍停止。至少实时或近1日取得有效数值后，才允许保存有效范围并进入订单，或推进自动更新状态。缺失范围始终明确提示，自动更新两小时后重试全量；不把空值改成零。

0.20.5 补充实际 Chrome 返回原生请求体读取错误、未提供任何原始片段的兼容情况。仍要求完整诊断、零原始片段与字节、无解析异常，以及 0.20.4 的全部美国站和同店铺新请求校验。0.20.4 已在真实浏览器确认前置证据通过，但此错误类型仍被拦截；0.20.5 的真实入库尚待验证。

0.20.4 兼容美国站概览和趋势请求参数在部分 Chrome 环境中不可读取的情况：仅在美国站商品流量页完成原生汇总时间范围刷新、恢复后，核对两个独立 POST 请求的准确地址、当前店铺和新请求时间，再使用已核实的美国站查询格式。可读取原生参数时仍优先使用原参数；其他站点、部分参数缺失、旧请求或店铺不符均拒绝继续。尚需实际采集入库验证，不能仅凭插件连接或测试通过判断已恢复。

自动流量优先使用已打开、独立确认属于同店铺的美国站流量页；每个时间范围采集前后核对来源和目标店铺以及目标地址。重试等待按实际站点与店铺隔离，避免国内站失败阻塞美国站。不会替用户切换店铺或修改候选页面地址。

0.20.3 修复流量原生请求信息在并发时被覆盖的问题。页面久停后缺少原生请求时，仅刷新汇总分析并恢复原时间范围，仍严格核对店铺和原生查询条件。包含 0.20.2 的手动采集启动修复。

0.20.2 修复手动采集启动时的 “Access to storage is not allowed from this context” 错误。采集与加速器的任务互斥检查由插件后台处理，保留原有存储访问权限。已安装本文件夹的 Chrome/Edge 用户在扩展管理中重新加载插件后，刷新商家后台页面即可生效。

统一包含经营数据采集、商品与活动、加速器状态同步、固定规则流量加速助手 1.0.6、商品下架、本地价格筛选、图片工具和页面浮层管理。

请在浏览器扩展管理中加载本文件夹。工作台网页默认使用 http://127.0.0.1:5173/，本机数据服务默认使用 http://127.0.0.1:18769/。首次使用请按整包安装说明配置本机连接；不共享个人账号、登录状态或经营数据。

流量加速器可从插件运营工具、美国站右下角“工具”或工作台流量加速器页面打开。打开面板不会自动扫描、填价或提交；先核对当前登录店铺、类目、标签及49/68/83元预设，再选择只读扫描或实际开启。

实际开启前会逐规格核对并保存待核实保护，已确认成功的商品14天内跳过。待核实结果必须人工核实。运行时采集任务与加速器互斥，暂停和停止保留。

旧独立助手与统一插件属于不同扩展ID，历史记录不会自动共享。请通过迁移补丁给原有助手增加完整JSON导出入口，再在统一助手相同店铺中导入。导入保留本机成功保护及待核实锁；不同待核实冲突或店铺ID不符会拒绝导入。未完成迁移核对前请保留原助手。CSV不能替代完整保护记录。
