# 流量加速助手 1.0.7（统一插件内置）

适用页面为 Temu 美国站 https://agentseller-us.temu.com/main/flux-analysis 。从工作台“流量加速器”、插件“运营工具”或卖家页右下角“工具”打开。打开只展示面板，不自动开始扫描或提交。

开始前核对当前登录店铺、筛选范围及本机历史记录。旧独立插件的记录不会自动共享给统一插件，需要完整 JSON 迁移并核对后再使用；结果 CSV 用于分析，不能替代成功保护和待核实记录。

默认预设：末级类目完整匹配“小盖毯、午休毯”，必须含独立“限时秒杀”标签并有唯一开启入口；持续14天；40*50in-法兰绒为49.00元、50*60in-法兰绒为68.00元、60*80in-法兰绒为83.00元。每位使用者必须按自己店铺修改和核对，不应把默认价格视为通用建议。

类目每行一个，满足任意一个；活动标签每行一个，全部满足。完整类目路径使用 > 分隔，不接受省略；只填末级类目时也要求末级文字完整。规格完整匹配尺寸、单位及材质，统一×、*、x及英寸/in写法，不混用厘米、英寸或其他材质。

“只读扫描”读取列表、慢速滚动和按分页翻页，不打开商品窗口、不填写价格。它核对网站总数与全部唯一商品ID，范围改变、遗漏或跨页重复导致覆盖不足会停止。已读数量和符合列表条件数量不代表已提交数量，SKU会在实际开启时另行核验。

“一键开启”会实际填写申报价并提交：逐件核对商品身份、全部SKU、参考价格、14天选中状态和档位中规格对应价格；任一校验不通过则跳过或停止，不擅改规则价格。只有本次提交后新出现明确成功提示才计成功。超时或未知结果保留“待核实”锁并停止；请在后台核实实际结果，再选择“已核实开启成功”或“已核实未开启”。不会自动继续任务。

成功商品按唯一goodsId保留14天跳过保护。成功、失败、待核实分别计数。刷新、离开或关闭页面会中断任务，记录保留但任务不自动继续。移除扩展会删除本机记录；换扩展ID也不共享存储。

运行时保持目标页面可见，不手动切店铺、筛选、页码或操作商品。可暂停、停止或收起；收起后仍可操作暂停/停止。停止时未提交窗口会取消，已经提交的仍等待结果。其他采集和流量任务互斥，不同时翻页。原自动更新会在完整扫描成功后恢复；停止或出错时保持暂停，可按需在原工作台重新开启。

默认扫描翻页间隔30秒，可设15至120秒，商品内操作间隔另设。只扫描一轮，服务器或网络异常会停止，不刷新或自动重扫。运行前可在网站先设每页100条并等加载完成，运行中改变每页条数会停止。成功报名使列表减少时，只接受不超过本轮明确成功数量的减少，并继续读取当前页补入商品；其他范围变化停止。

结果可导出CSV，规则可导入/导出JSON。“历史记录备份与迁移”导出包含成功保护、待核实、规则和任务的完整JSON；文件只下载到本机。导入最大5MB，核对当前店铺ID，合并成功保护但不延长原期限、不覆盖已有配置。不同待核实记录冲突或多个未核实结果时拒绝导入，原记录保留。历史记录可能包含商品、价格与店铺标识，由本人决定是否分享。

旧助手记录没有店铺归属字段，因此旧版导出补丁要求本人填写来源店铺数字ID；应按原记录实际所属店铺核对，不得把手填ID视为自动验证。保留原插件及其数据，直到统一插件导入成功且数量和待核实记录核对无误。补丁必须覆盖原扩展文件夹并重新加载原扩展，不要另装为新扩展。

页面诊断导出包含商品标识、文字及简化DOM，不读取密码、Cookie或登录令牌。业务操作通过页面已有按钮和表单，不调用未公开业务接口；插件不会外传此工具的记录。固定14天不代表修改自动续期设置；续期需自行在Temu后台核对。本版本没有批量关闭加速器流程。

当前整合在本地模拟与浏览器隔离环境验证。不同真实店铺的网站状态、完整扫描和实际提交仍需由使用者分别核对，不能把模拟通过解释为真实业务已成功。
