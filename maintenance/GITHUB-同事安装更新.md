# 同事在线安装和更新

适用 Windows 10/11、Intel/AMD 64位电脑。安装包自带 Python 和专用 Chrome；不要求系统安装 Python、Node、Git 或管理员权限。使用 Git 获取源码的同事需要自己安装 Git；只使用正式安装包不需要 Git。

1. 首次可到 https://github.com/BMingyue/Temu-/releases/latest 下载 `TextileWorkbench-Setup-版本.zip`，全部解压，双击安装入口。不要下载 GitHub 自动生成的 Source code ZIP 作为安装包。
2. 从 Git clone/pull 获得源码后，双击根目录 `从GitHub安装更新.cmd`；已安装工作台内同名入口也可使用。
3. 入口读取本仓库最新正式 Release，校验所选资产的地址、完整 SHA256 和 ZIP 结构。已有受支持基线时使用对应小更新；没有匹配基线但识别到旧版时，先只读校验完整包，再用其自带更新器打开保留数据的原地更新向导。只有没有旧安装时才进入首次安装向导。
4. 更新前正常完成任务、关闭专用浏览器和店小秘。忙任务、错误基线、程序被改动或路径不合要求会由原更新器停止；不会强制覆盖。
5. 首次登录自己的 Temu、ChatGPT、店小秘；商品目录、资质、模板及业务规则仍按当前电脑设置。登录状态和私人资料不从发布者电脑复制。

入口优先识别自身所在的安装目录，再检查桌面“织品工作台”快捷方式。源码仓库不能作为覆盖目标。没有识别旧安装时会打开首次安装向导；已有旧版请先关闭向导，再用明确路径运行更新，避免创建新的空数据安装：

```powershell
.\从GitHub安装更新.cmd -Target "D:\TemuWorkbench"
```

如果希望找不到原安装就直接停止，使用 `-Mode Update`。`-Mode Install` 强制使用完整包；如已识别旧安装，仍走保留数据的完整更新，不进行全新安装。

仅下载、校验、解压，不安装或停止服务：

```powershell
.\从GitHub安装更新.cmd -DownloadOnly -CacheRoot "D:\TWDownloads"
```

`-CheckOnly` 在下载校验后调用原安装/更新器的只读检查，不进行安装。缓存保留在提示的临时目录，校验失败时不运行其中的程序。网络受限时可从同一 Release 下载完整离线 ZIP；不要从不明镜像运行脚本。路径过长时可用上面的 `-CacheRoot` 指向一个较短、可写、在原安装目录之外的真实目录。

程序只保留数据，不会自动恢复未知业务提交：过去待核实的报名、调价、上架或生图结果需要按原界面核对。更新入口不会操作商品、启动采集或执行上述业务。

维护发布约定：tag为 `v版本`；正式完整包为 `TextileWorkbench-Setup-版本.zip`，基线小包为 `TextileWorkbench-Update-from-原版-to-新版.zip`；`SHA256SUMS.txt` 每行为“64位十六进制SHA256、两个空格、资产文件名”。发布前完成干净安装及各支持基线升级验收。草稿和预发布版不会由本入口采用。
