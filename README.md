# 店小秘自动上架独立版源码

Windows 独立版维护源码，业务逻辑和重建步骤见 `维护说明.md`。成品 exe、浏览器和用户账号数据不纳入 Git。

双击 `Git版本管理.cmd` 可保存本地源码版本、连接自己的私有仓库并推送；详细步骤见 `GIT使用说明.md`。Git 拉取仅更新源码，不自动构建、上传商品或恢复任务。

维护顺序：修改源码 → 离线检查 → 构建纯发布包 → 自检 → 在织品工作台中“同步店小秘新版” → 构建工作台增量更新包。用户自行登录并核对图片、模板和发布模式后才开始业务。

用户配置、状态、浏览器登录、失败现场和日志保存在独立的用户数据目录，不能提交到仓库或复制到发布包。
