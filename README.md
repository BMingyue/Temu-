# 织品工作台

巡店、维护、上新三个板块的本地 Windows 工作台。本仓库保存源码、扩展和模板；运行数据、账号登录、依赖和安装包留在各自电脑。

## 同事首次安装和更新

Windows 10/11 Intel/AMD 64位电脑，推荐使用[最新正式安装包](https://github.com/BMingyue/Temu-/releases/latest)。完整包带 Python 和专用 Chrome，无需系统 Python、Node 或编程环境。下载完整安装 ZIP 后全部解压，再双击其中的安装入口；自己的 Temu、ChatGPT、店小秘账号需本人登录。

如果已通过 Git 拉取本仓库，双击根目录 **从GitHub安装更新.cmd**。它自动获取同一仓库的正式 Release、匹配当前安装基线、校验 SHA256，然后打开原安装或更新器；已有安装使用保留数据的小更新，或校验完整包后进入原地更新向导，拒绝在任务运行时强制覆盖。安装版也带这个更新入口。网络受限时可转发原始离线安装 ZIP，不要转发用过的安装目录。

`git pull` 只更新源码，不能直接升级已运行的安装版。具体步骤、路径参数及仅下载模式见 [同事在线安装更新说明](maintenance/GITHUB-同事安装更新.md)。

## 第一次使用 Git

双击本目录 `Git版本管理.cmd`，可查看改动、保存版本、连接自己的仓库。首次远程配置参见 `GIT使用说明.md`。不要通过网页直接上传整个工作台文件夹。

- 本地保存：核对变更清单，填写说明并提交。
- 远程备份：连接自己的 GitHub/Gitee 仓库后推送。首次认证在 Git 自己的登录窗口完成。
- 拉取源码：工作区必须干净，只允许快进；拉取不会代替安装、构建或业务验收。
- 同事更新：双击 `从GitHub安装更新.cmd` 获取已验证的正式安装/更新包，或使用对应基线的离线小更新；同事无需 Git 或编程环境。

## 同步店小秘

双击 `同步店小秘新版.cmd`，选择纯发布目录；工具校验来源版本及全部文件后同步组件。`workbench-components.json`统一记录组件版本，账号与完成记录保留在用户目录。

独立店小秘源码在独立 Git 工作目录维护，可推送到统一远程仓库的 dianxiaomi-uploader 分支，本仓库不提交其 exe 或自带浏览器。维护人员先构建并验收独立版，再同步发布文件；源码提交不表示线上上架验证完成。

## 构建和分发

页面使用锁定依赖，执行 `node node_modules/vite/bin/vite.js build --config release/vite.portable.config.ts`。
`release/build_workbench_bundle.py`生成干净完整包；`release/build_delta_update.py`比较两份已验证完整包生成离线增量更新。完整首次安装带运行环境，后续小更新仅携带差异文件。

同事首次仍自行登录 Temu、ChatGPT、店小秘，配置真实商品目录、模板和资质。不要将使用过的安装目录作为分发包。工作台默认地址为 http://127.0.0.1:5173/ 。
